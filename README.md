# $0 → $100 AI Experiment Website

## Before publishing
1. Open `index.html`.
2. Replace both instances of `https://buymeacoffee.com/YOUR_PAGE` with your actual Buy Me a Coffee page.
3. When money comes in or is spent, add an entry to the `ledger` array near the bottom of the file.

Example:
{date:"2026-09-11", type:"Contribution", description:"Support from experiment participant", amount:1.00}

Expenses are negative:
{date:"2026-09-12", type:"Expense", description:"Domain name", amount:-12.00}

## Publishing
This is a static site and can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or similar services.
