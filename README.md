# $0 → $100 AI Experiment Website

The website is centered on the overall **$0 → $100 experiment**. Cannon Cove is one project inside it.

## Device handling
There is one `index.html`. It uses responsive CSS media queries to automatically load the appropriate layout for the visitor's screen. There is no mobile/desktop chooser or button.

## Files
- `index.html` — responsive main site
- `experiment-log.html` — public log
- `progress.html` — financial progress
- `policy.html` — support/refund policy
- `site-data.js` — shared experiment data

## Ledger
Revenue counts toward $100. Voluntary support is separate. Expenses are recorded separately. The current ledger includes the $20 Claude Pro subscription expense.
