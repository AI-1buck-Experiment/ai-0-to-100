A real little experiment

Can I turn $0 into $100?

I'm starting with nothing set aside for this project and seeing how far I can get using time, creativity, the internet, and a few honest attempts.

No magic button. Just trying things and keeping track.

What's the point?

— honestly, I'm curious.

Start small

The goal is deliberately tiny: make the first $1, then $10, then keep going. I want the process to be more interesting than pretending I already know the answer.

Keep it honest

I'll record what I try, what works, what doesn't, and where the money actually comes from. Failed ideas still count as part of the experiment.

Learn something useful

If this reaches $100, great. If it doesn't, I'll still have a record of which ideas were worth pursuing and which ones weren't.

You're welcome to watch

This site is the little notebook for the project. Nothing here is supposed to look bigger, smarter, or more successful than it really is.
