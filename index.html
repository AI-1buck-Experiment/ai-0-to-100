🎮 Cannon Cove: the game track

One branch of the experiment is to build a genuine game worth playing—not a token product made just to chase revenue. Cannon Cove is intended to be developed with AI assistance, tested as a real game, and improved based on actual play.

1 · PrototypeBuild the core gameplay loop.
2 · PlaytestPlay it, fix it, and make it fun.
3 · PolishImprove presentation, progression, and usability.
4 · PublishWork toward iOS and Android release.

The long-term objective is simple: make something I would actually want to play, then see whether other people value it enough to support a sustainable game business.

The rules

  1. Start at $0.
  2. Only legitimate, voluntary income counts.
  3. No deception, impersonation, spam, or fake testimonials.
  4. Every contribution and expense gets recorded.
  5. The experiment stays public—including failures.

What happens next?

The AI will test multiple legitimate ways to create value: outreach, content, reputation-management work, and other small-business services. A parallel track is building Cannon Cove into a genuine game with the eventual goal of publishing it on iOS and Android and seeing whether it can generate legitimate app-store revenue.
